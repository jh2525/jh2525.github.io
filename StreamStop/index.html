Abstract

Reasoning-enabled language model agents can incur substantial computation before acting, although the reasoning needed varies across decisions. Existing stopping signals, such as confidence and intermediate-answer stability, can vary in effectiveness across reasoning models; signals obtained from hidden states or token probabilities also require internal access that may be unavailable or impractical. We introduce StreamStop, which learns model-specific stopping policies offline from prefix-level action agreement. A frozen prefix reader encodes available reasoning text for a lightweight stop head, allowing stopping without access to the reasoning model's internal signals. We construct and publicly release a dataset of agent reasoning trajectories with prefix-level action annotations. These annotations compare each prefix action with the full-reasoning reference action, enabling offline comparison of stopping rules and exact expected-return optimization of a discounted action-agreement objective. Conditioning the head on the discount factor allows the agreement–token trade-off to be adjusted at inference without retraining. In closed-loop evaluations on WebShop and ScienceWorld, StreamStop achieves higher observed success than most validation-selected fixed-budget settings while using fewer reasoning tokens than Full thinking. On WebShop with Qwen3.8-27B, it uses 42% fewer reasoning tokens per episode with similar observed task success.

How much reasoning does one decision need?

Language model agents can generate substantial reasoning before acting, but the amount needed varies across decisions. A short fixed budget can interrupt useful reasoning; a long one can continue after the action is already determined. StreamStop learns when the available reasoning is sufficient to preserve the reasoning model's full-reasoning action.

A small reader guides adaptive stopping

The reasoning model \(\mathcal M\) streams its reasoning in chunks. After each chunk a frozen prefix reader \(\mathcal R\) encodes the prefix read so far, and a lightweight stop head \(\pi_\theta\), conditioned on a discount factor \(\gamma\), chooses between two control actions:

WAITReceive the next reasoning chunk and update the stopping decision.
STOPAsk \(\mathcal M\) to generate an action from the selected prefix.

Once trajectories and prefix-action annotations have been collected, the stop head is trained offline without additional reasoning-model calls or environment rollouts. Both language models remain frozen. Each annotated prefix \(t\) of a recorded trajectory \(\xi\) is labelled with whether the action generated from it agrees with the full-reasoning action, \(y_t\in\{0,1\}\), and the expected discounted agreement is computed exactly over stopping times on each recorded trajectory, with \(q_t\) the probability of first stopping at prefix \(t\):

\[ J(\theta \mid \xi, \gamma) = \sum_{t=0}^{T} q_t\, \gamma^{t}\, y_t . \]

The head is conditioned on \(\gamma\), so a single trained policy supports different agreement–token trade-offs without retraining. Smaller values place more weight on early agreement; values closer to one place less penalty on waiting.

Results

StreamStop achieves higher observed success than most validation-selected fixed-budget settings across the evaluated environment–model configurations. On WebShop with Qwen3.8-27B, it uses 42% fewer reasoning tokens per episode with similar observed success to Full thinking. The relative performance of confidence- and consistency-based stopping varies across reasoning models, motivating a stopping criterion learned from each model's prefix-action behavior.

Text-based stopping with a closed-weight model

Gemini 3.1 Flash-Lite provides an API-based proxy evaluation of the stopping interface. We disable native thinking and elicit an explicit plan, then ask the same model to act from a selected plan prefix. This evaluates stopping without hidden-state or token-probability access; the reported tokens measure selected plan text, not API billing savings from interrupting native reasoning.

Decision Latency and Reader Overhead

StreamStop reduces decision latency relative to Full thinking for the evaluated local reasoning models. Prefix reading overlaps generation; waiting for the reader accounts for a median 0.56% of mean decision latency across the evaluated StreamStop settings.

A dataset of reasoning prefixes with their actions

A completed reasoning trajectory records the final action, but does not reveal which action the model would generate from an earlier prefix. We collect prefix-action annotations by asking the reasoning model to act from intermediate prefixes while holding the environment context fixed. These annotations enable offline training and comparison of stopping rules on the same recorded decisions, using action agreement and reasoning tokens used.
